## ✨ Features & Highlights

- **Dynamic VOZX.AI Status Pill**: Real-time neural heartbeat pill at the top of the interface showing AI engine status and connectivity.
- **CyberGuard 365/Day Shield Gauge**: Glowing SVG radial arc gauge displaying annual phishing attack prevention statistics and system health.
- **Threat Scanner**: Real-time phishing URL, SMS, and QR code detection scanner with interactive scanning animations and simulated threat analysis.
- **Customizable User Profile**: Floating user greeting card with a male avatar and an interactive modal to edit name, role, and avatar picture.
- **Emergency SOS Protocol**: One-tap emergency lockdown trigger with audio siren synthesis, animated warning overlays, and simulated geolocation dispatch.
- **Glassmorphism & Cyberpunk Styling**: Deep navy background (`#030D1A`), electric blue/cyan neon glows, blurred backdrops, and rounded Material 3 cards.
- **Responsive Mobile Shell**: Centered mobile viewport frame on desktop screens and edge-to-edge native app feel on mobile smartphones.

## 🚀 Quick Start

No installations, build tools, or compilers required!

### Method 1: Direct File Open
1. Clone this repository:
   ```bash
   git clone https://github.com/Varunreddy1207/My-Web-Development-Projects-.git
   ```
2. Double-click `index.html` to open it in your browser.

### Method 2: Local HTTP Server (Python)
```bash
python -m http.server 8000
```
Open `http://localhost:8000` in your browser.
